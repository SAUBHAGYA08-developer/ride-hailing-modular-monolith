TTL —
Read the gap, not the totals. byStatus is what MySQL reserved; reportingLocation is who still has a fresh position in the Redis GEO set. A driver on duty whose last ping is older than the TTL is a ghost — MySQL calls them AVAILABLE, dispatch cannot see them, and they will never be matched. Coordinates are the live Redis position. Snapshot is the MySQL recovery copy, written only at go-online and ride-end, so it lags a moving driver by design. bookable (AVAILABLE + live position + an active vehicle) is the only honest answer to "how many drivers can take a ride right now".
A 403 here is almost always a stale token: authorities are baked into the JWT at login, so an admin signed in before the DRIVER_FLEET_READ migration ran carries a token without it. Log out and back in — no server change needed.
